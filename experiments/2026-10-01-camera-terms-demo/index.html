카메라 무브 도감Camera moves / 8 specimens

카메라 무브 용어 8개를 CSS 애니메이션으로 재현했습니다.
뷰파인더 안에서 움직임의 차이를 확인하고, AI에게 지시할 때 쓸 문장 예시도 함께 붙였습니다.

SOURCE / 원본 출처 Threads @juuouse ↗

카메라 기본 용어를 정리한 글의 여덟 가지 개념을 요약하고, 각각의 움직임을 CSS로 재구성했습니다.

재현 방법과 실험 기록 ↗

기기의 모션 감소 설정에 따라 자동 재생을 멈췄습니다. 각 카드의 ‘재생’을 누르면 한 번만 움직입니다.

SPECIMENS / 표본 01–08

  1. 01 / 08

    팬Pan

    카메라 위치는 그대로 두고 몸통만 좌우로 돌립니다. 화면 속 장면이 옆으로 훑고 지나갑니다.

    Prompt / 지시 예시“첫 화면에서 오른쪽으로 팬해줘. 1초 동안.”

    move 1s · loop 4s

  2. 02 / 08

    틸트Tilt

    제자리에서 고개를 들거나 숙이듯 위아래로 돌립니다. 높은 건물이나 제품의 아래위를 훑을 때 씁니다.

    Prompt / 지시 예시“제품 아래에서 위로 틸트 업해줘. 1.5초.”

    move 1.5s · loop 6s

  3. 03 / 08

    롤Roll

    렌즈가 향한 방향은 그대로 두고 카메라를 기울입니다. 수평선이 비스듬해져 불안하거나 긴장된 느낌을 줍니다.

    Prompt / 지시 예시“마지막 컷에서 화면을 5도 롤해줘. 0.5초.”

    move 0.5s · loop 2s

  4. 04 / 08

    트럭Truck

    카메라 몸체가 옆으로 평행 이동합니다. 가까운 물체는 빨리, 먼 물체는 느리게 스쳐 가 깊이가 생깁니다.

    Prompt / 지시 예시“카드 세 장을 따라 왼쪽으로 트럭해줘. 2초.”

    move 2s · loop 8s

  5. 05 / 08

    페데스탈Pedestal

    카메라를 수직으로 올리거나 내립니다. 렌즈 각도는 그대로 두고 높이만 바뀌므로 고개를 드는 틸트와 구분됩니다.

    Prompt / 지시 예시“건물 아래에서 위로 페데스탈 업해줘. 2초.”

    move 2s · loop 8s

  6. 06 / 08

    달리Dolly

    카메라 몸체가 대상 쪽으로 다가가거나 멀어집니다. 앞뒤 사물의 크기 비율이 바뀌어 원근감이 함께 달라집니다.

    Prompt / 지시 예시“캐릭터 쪽으로 달리 인해줘. 배경도 같이 변하게. 1.5초.”

    move 1.5s · loop 6s

  7. 07 / 08

    줌Zoom

    카메라는 제자리에 둔 채 렌즈 초점거리만 바꿔 대상을 당겨 옵니다. 배경과 대상 사이의 거리감은 그대로입니다.

    Prompt / 지시 예시“제목에 줌 인해줘. 1초.”

    move 1s · loop 4s

  8. 08 / 08

    오빗Orbit

    대상을 중심에 두고 그 둘레를 돕니다. 대상은 제자리에 있고 보이는 면과 배경이 함께 바뀝니다.

    Prompt / 지시 예시“제품 주위를 180도 오빗해줘. 3초.”

    move 3s · loop 12s
